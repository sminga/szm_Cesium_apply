# example

可运行的 Cesium 风场工作台。`index.html` 负责页面骨架，`app/main.js` 负责 Cesium、风场和界面交互，`ui/index.css` 负责双侧工作台及响应式样式。

## 启动

在项目根目录运行：

```powershell
npm run dev
```

浏览器打开 Vite 输出的地址。页面启动后会自动加载 `data/wind_3d.json` 作为示例三维风场。

需要访问 `tools/converted`、转换 NetCDF、把非 GeoTIFF DEM 离线生成 quantized-mesh，或合并开发者本地地形时，再启动本地服务：

```powershell
npm run local:server
```

本地服务默认监听 `http://127.0.0.1:8765`。

## 页面布局

### 顶部模式栏

- **风场**：在页面顶部选择并处理 NC 文件，加载二维/三维风场，设置高度范围和渲染参数。
- **场景**：选择 Cesium、OpenStreetMap、天地图、高德、百度、腾讯、Google ion、星图或无底图；按需打开 Sentinel-2、Google Photorealistic 3D Tiles 和 Cesium OSM Buildings。
- **地形**：启用 Cesium World Terrain，一次选择多份本机 GeoTIFF 作为局部 DEM，或从电脑文件夹加载处理后的 quantized-mesh 基础地形；同时管理公开目录、定位、恢复椭球和局部 DEM 优先级。
- **工具**：创建和命名临时地图点位、绘制并播放 GLB 模型路线、点击拾取经纬度，以及从本地 GeoJSON/TopoJSON/Shapefile 文件加载矢量数据。文件不上传，刷新页面后清除。

顶部右侧显示当前二维/三维风场数量，并提供定位当前图层和同时开合两侧面板的快捷按钮。

顶部模式栏使用标准页签语义。键盘焦点位于模式按钮时，可以使用左右方向键切换相邻模式，使用 `Home` 跳到“风场”，使用 `End` 跳到最后一个模式；当前模式和左侧内容面板会同步更新。

### 左侧参数面板

左侧面板内容随顶部模式切换。风场页保留以下功能：

- 从项目目录或本机文件系统加载二维、三维 NC 文件。
- 显示当前风场速度色带。
- 对三维风场选择全部高度、连续范围或离散单层。
- 调整粒子密度、流动速度、低速显眼度、高度拉伸、最大线长和高速区密度。每项参数同时提供滑块和数值填写框：滑块适合快速调整，填写框适合输入精确值；提交填写值时会按对应 `min/max/step` 自动校正并同步滑块。流动速度使用低速端更精细的比例滑块，实际范围为 `0.05～5`、默认 `0.3`。最大线长范围为 `20～240 px`、默认 `80 px`，区域近景直接控制可见线长，全球远景会自动衰减以避免变形。
- 每项参数名称旁显示默认值。点击“恢复默认”会一次性恢复六项数值渲染参数，不改变“按风速加密”和“动画”两个开关的当前状态。

### 中央地图

地图右上角提供回到初始视角、放大、缩小和定位当前风场按钮。地图左右边缘的窄按钮用于开合参数面板和图层面板。

### 右侧图层面板

右侧“图层管理”按数据任务、底图、影像叠加、矢量、风场、3D 内容、基础地形和局部 DEM 分组显示：

- 资源按能力提供显隐、定位、移除、透明度、设置或激活；数据任务提供适用的取消、重试和移除。
- 影像叠加层可以调整实际影像栈顺序；风场和 3D Tiles 的列表次序不改变深度遮挡；底图固定在影像底部。
- “基础地形”保留多个候选但只激活一个；“局部 DEM”可以同时启用多个，列表越靠上，重叠区优先级越高。Cesium 最终仍只接收一个组合 `terrainProvider`。
- 二维风场可以直接修改固定显示高度。场景状态同时显示底图、影像、3D Tiles 和地形状态。

基础底图可能由多个内部影像层组成，例如天地图“影像 + 境界线 + 中文注记”，但右侧只显示一个逻辑底图条目。隐藏或调整透明度会同时作用于整组；切换底图不会删除 Sentinel-2 等独立影像叠加层。天地图的“地形晕渲图”只是二维影像，真实高程仍在“地形”页管理。

### 底部状态栏

状态栏显示本地服务状态、WebGL 版本、鼠标位置经纬度、相机高度和实时 FPS。

### 火场服务

“火场服务”页签用于接入 Fireflow 分发 API，提供身份选择、产品目录、幂等申请、状态轮询、摘要、科研图预览和附件下载。功能默认关闭；只有内网同源 HTTPS 入口配置 `VITE_FIREFLOW_ENABLED=true` 时启用。当前不自动加载 NetCDF-4，也不把没有真实地理配准的图片放到地图，完整边界见 `docs/Fireflow分发服务侧栏接入.md`。

## 响应式行为

- 宽度大于 `900px` 时，参数面板、地图和图层面板组成三列工作区。
- 宽度不大于 `900px` 时，左右面板变为覆盖地图的抽屉，并且一次只打开一个。
- 宽度不大于 `560px` 时，顶部模式栏只显示图标，状态栏隐藏次要坐标信息。
- 触屏设备始终显示图层操作按钮，不依赖鼠标悬停。

## 地图标注、路线与矢量工具

打开顶部“工具”后，地图操作模式一次只激活一种。点位和路线可以命名、定位和删除，并同步显示在右侧“矢量数据”分组。模型路线由访客在当前浏览器选择单文件 `.glb` 后绑定；`.gltf` 外部依赖和多文件模型不支持。模型最多 100 MiB。

坐标拾取显示 WGS84 经纬度、位置高度和高度来源，依次尝试场景深度、地形表面和椭球。矢量文件支持 `.geojson`、`.json` 和 Shapefile `.zip`；也可以同时选择同名的 `.shp/.dbf/.prj/.cpg` 配套文件。总大小最大 50 MiB、最多 100,000 个要素；TopoJSON 和 Shapefile 会在浏览器转换为 GeoJSON。

点、路线、模型、矢量内容和名称只存在当前页面会话，不会上传给 Vercel 或第三方，刷新/关闭后不会保留。详细操作和限制见 [`docs/工具页地图标注与路线.md`](../docs/工具页地图标注与路线.md)。

## 浏览器预览本地 DEM

公开网站和开发环境都可以在“地形”页点击“选择并加载 DEM（可多选）”，选择一份或多份 `.tif` / `.tiff`：

- EPSG:4326 和 WGS84 UTM 南北半球分区在 Web Worker 中解析、重投影和采样。
- 文件不会上传，也不需要 `npm run local:server`、Python 或 Docker。
- 成功后自动定位到已启用 DEM 的联合范围，并在右侧逐项显示；关闭某一 DEM 会释放其 Worker，切换基础地形不会移除其他 DEM。
- 结果只存在于当前标签页，刷新后不会保留，也不会生成 `.terrain` 文件。
- `.img`、`.asc`、`.dem`、其他投影和需要长期发布的数据仍走离线工具。

页面不再以约 4.5 MB 作为 GeoTIFF 上限。实际可处理大小取决于浏览器内存和栅格规模；本次已用 58.1 MB WGS84 GeoTIFF 和 7.1 MB UTM 50N GeoTIFF 完成生产预览验证。完整边界见 `docs/浏览器本地DEM加载.md`。

## 地形发布流程

1. 使用 `py tools/terrain/build_quantized_mesh.py <DEM>`，或在开发环境启动 `npm run local:server` 后通过页面处理 DEM。
2. 在“地形管理”区域点击“加载本地文件夹”，选择包含 `layer.json` 和 `.terrain` 瓦片的处理结果；文件只在当前浏览器中读取，不会上传。
3. 确认地形可以加载，并且“定位当前地形”飞到真实 `valid_bounds`。
4. 将小型数据发布到 `example/public/terrain`，或将大型数据上传到对象存储/CDN。
5. 更新 `example/public/terrain/catalog.json`，再执行 `npm run build:vercel`。
6. 公开用户从“地形”模式选择已发布数据并加载。

只有“生成可持久化 quantized-mesh”需要 Docker Desktop；浏览器即时预览 GeoTIFF 不需要。更完整的部署边界见 `docs/公开地形与Vercel部署.md`，转换说明见 `tools/terrain/README.md`。

## 环境变量与生产构建

- 复制 `example/.env.example` 为 `example/.env.local`，可配置 Cesium ion、天地图和部署者授权的高德/百度/腾讯/星图瓦片服务、本地开发服务及受控同源 Fireflow 入口。
- 未配置 ion Token 时默认使用 OpenStreetMap，并禁用 Google ion、Sentinel-2、3D Tiles 和世界地形；未配置其他厂商时，对应下拉项显示“未配置”并禁用。
- `VITE_*` 会进入浏览器包，所有 Token/Key 都必须限制允许域名、服务范围和配额，不能放置私密服务端密钥。
- Cesium credit 容器必须保持可见，以显示 OpenStreetMap、Google、Sentinel、Cesium ion 和其他数据提供者署名。
- `npm run build:vercel` 构建公开工作台到 `site-dist`；`npm run build` 仍负责 npm 库产物。

多厂商底图、坐标系和 URL 模板详见 [`docs/多厂商底图与坐标系适配.md`](../docs/多厂商底图与坐标系适配.md)。

## 维护约束

- 不要随意修改业务控件的 `id`；`app/main.js` 使用这些 `id` 绑定事件和更新状态。
- 面板尺寸变化后必须调用 `viewer.resize()`，避免 Cesium 画布比例和拾取位置错误。
- 风场图层列表由 `renderWindLayerList()` 统一渲染，不要维护第二份图层数据。
- 详细布局方案和控件迁移表见 `docs/UI布局改版方案.md`。
- 统一图层能力、处理任务状态、排序限制和未来格式接入规则见 `docs/统一场景图层管理方案.md`。
