# UI 设计草案

`ui_design_test/` 保存工作台改版过程中使用的独立 HTML 草案，用于比较信息架构、布局和视觉方向。它们不是正式页面入口，也不会由当前 Vercel 构建配置发布。

## 文件

| 文件 | 用途 |
| --- | --- |
| `01ui_test.html` | 早期轻量布局实验。 |
| `02.html` | 较完整的工作台布局和控件方案实验。 |
| `03.html` | 后续视觉与交互结构草案。 |

## 使用和维护

- 可以直接在浏览器打开进行静态比较，但其中的交互和数据不代表正式功能。
- 正式实现以 `example/index.html`、`example/app/main.js` 和 `example/ui/index.css` 为准。
- 从草案迁移设计时，应重新使用正式控件、Lucide 图标、响应式规则和 Cesium 生命周期，不要直接复制可能过时的模拟代码。
- 草案不应引用真实 Token、私密数据或开发者绝对路径。
- 新的正式设计决策应记录到 `docs/UI布局改版方案.md`，而不是只保留在实验 HTML 中。
