# 项目结构

## 源代码

| 目录 | 职责 |
| --- | --- |
| `src/core` | 公共图元、配置合并、着色器装配和高度模式换算 |
| `src/data` | NetCDF-3 读取、数据重排和速度加权粒子播种 |
| `src/wind-2d` | 将 U/V 风场固定在指定绝对高度显示 |
| `src/wind-3d` | 三维风场图层、相机范围和 Cesium 生命周期 |
| `src/layers` | 同时管理多个二维与三维风场图层 |
| `src/rendering` | WebGL2 三维纹理、GPU 粒子计算与流线绘制 |
| `src/shaders` | GLSL 速度、位置、重生和线段着色器 |
| `src/terrain` | 标准 Cesium quantized-mesh 地形加载入口 |

`src/index.js` 是统一公共入口。目录调整后，外部仍可继续从包名导入 `WindLayer3D`。

## 示例页面

| 目录 | 职责 |
| --- | --- |
| `example/app` | Cesium Viewer 和 GUI 业务入口 |
| `example/ui` | 顶部模式栏、双侧工作面板、地图控件、状态栏与弹窗样式 |
| `example/services` | 公开地形目录与开发者本地 Python 服务客户端 |
| `example/public/terrain` | 随网站部署的公开地形清单和可选小型数据集 |
| `example/config` | 旧版 Token 配置说明和兼容模板 |
| `example/data` | 示例风场数据 |

示例页面的主要文件：

| 文件 | 职责 |
| --- | --- |
| `example/index.html` | 工作台 DOM 骨架；包含顶部栏、左侧参数面板、地图、右侧图层面板、状态栏和目录弹窗 |
| `example/app/main.js` | 初始化 Cesium，管理风场/地形/底图，并绑定页签、面板、地图工具和状态栏交互 |
| `example/ui/index.css` | 视觉令牌、桌面三列布局、移动端抽屉、控件和弹窗样式 |
| `docs/UI布局改版方案.md` | UI 信息架构、控件迁移表、设计令牌和后续维护建议 |

### 示例页面数据流

1. `index.html` 提供稳定的控件 `id` 和布局容器。
2. `main.js` 通过 `WindLayerManager` 管理风场数据，并将当前状态渲染到右侧图层列表。
3. `terrainCatalogClient.js` 读取公开目录，开发模式下可合并 `localServiceClient.js` 返回的开发者本地地形。
4. `localServiceClient.js` 只在开发模式或显式开启本地工具时访问 Python 服务并提交转换任务。
5. `index.css` 通过 `body.left-panel-closed` 和 `body.right-panel-closed` 控制面板尺寸；面板变化后由 `main.js` 调用 `viewer.resize()`。

桌面端采用“参数面板 + 地图 + 图层面板”三列结构。宽度不大于 `900px` 时，左右面板改为互斥抽屉，地图保持全宽。

## 本地工具

| 目录 | 职责 |
| --- | --- |
| `tools/netcdf` | NetCDF-4/HDF5 到标准 NetCDF-3 的转换 |
| `tools/terrain` | 调用 Docker CTB 生成 quantized-mesh |
| `tools/server` | 风场目录、文件下载、格式转换和地形托管服务 |
| `tools/converted` | 转换完成的 NC 文件，运行时目录 |
| `tools/terrain-output` | 生成的标准 Cesium 地形，运行时目录 |
| `tools/uploads` | 网页上传的临时文件，处理后自动删除 |

## 测试

测试按职责分到 `tests/core`、`tests/data`、`tests/example`、`tests/layers`、`tests/terrain` 和 `tests/tools`，分别覆盖基础工具、数据加载、公开目录、风场高度逻辑、地形控制器与本地工具。

## 构建输出

| 命令或文件 | 职责 |
| --- | --- |
| `npm run build` | 构建 npm 库到 `dist` 并生成发布包目录 |
| `npm run build:vercel` | 构建公开示例网站到 `site-dist` |
| `vite.example.config.js` | 公开站点生产构建配置 |
| `vercel.json` | Vercel 构建命令和输出目录配置 |
