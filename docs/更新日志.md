## 2026-09-22：二维/三维多风场、本地目录和 DEM 地形

### 多风场图层

- 新增 `WindLayer2D`。二维文件读取 U/V 后自动把 W 设为 0，并固定在用户指定的绝对高度。
- 新增 `WindLayerManager`，允许一个 Cesium Viewer 同时显示多个二维风场和多个三维风场。
- 二维风场目录支持多选文件，使用“起始高度 + 层间距”自动把多个文件放置到不同高度。
- 风场图层列表支持选择当前层、显隐、定位和删除。
- 每个二维图层可以在图层列表中单独修改显示高度。

### 三维高度控制

- 增加“全部高度”模式，显示文件内完整三维高度范围。
- 增加“连续范围”模式，用户可以填写最低和最高显示高度。
- 增加“离散单层”模式，从 NetCDF 的真实高度层中选择一个高度。
- 高度限制同时作用于初始粒子播种、粒子越界重生、GPU 垂直运动和最终绘制，不是仅在界面上隐藏。
- 对非等距高度层增加分段归一化，避免直接按最高/最低高度线性换算造成采样层偏移。

### 默认风场目录

- 浏览器不能强制系统文件对话框第一次打开任意 Windows 绝对路径，因此改为网页内置文件目录。
- 本地服务新增 `/api/wind-files`，默认列出 `tools/converted` 中的 `.nc` 和 `.cdf` 文件。
- 本地服务新增 `/files/wind/...`，网页可直接读取目录中的文件。
- 加载按钮优先打开项目文件目录，同时保留“浏览其他位置”作为备用入口。

### 本地 DEM 与 quantized-mesh

- 参考 `cesium-terrain-builder-docker`，新增 `tools/terrain/build_quantized_mesh.py`。
- 处理流程为 GDAL 重投影到 EPSG:4326，然后使用 CTB 生成 Mesh 瓦片和 `layer.json`。
- 默认 Docker 镜像为 `tumgis/ctb-quantized-mesh:latest`，可通过服务参数替换。
- 本地服务新增 DEM 上传处理接口、地形目录接口和静态瓦片托管。
- 前端新增“选择并处理 DEM”“刷新地形列表”“加载地形”和“恢复椭球地形”按钮。
- 前端使用 `CesiumTerrainProvider.fromUrl()` 加载标准 quantized-mesh，生成结果可供其他 Cesium 项目使用。
- 当前开发机器没有安装 Docker，因此已验证错误提示路径，但未在本机实际生成 DEM 瓦片。

### 项目整理

- 将核心代码拆分为 `core/data/wind-2d/wind-3d/layers/rendering/shaders/terrain`。
- 将示例拆分为 `app/ui/services/config/data`。
- 将本地工具拆分为 `netcdf/terrain/server`。
- 将测试拆分为 `core/data/layers`。
- 每个功能目录都增加中文 `README.md`，说明职责、输入输出和主要文件。
- 保留 `src/index.js` 统一导出，减少目录迁移对外部使用方式的影响。

- Docker 不可用时，DEM 接口返回清晰错误，不会导致服务退出。
- 新增非等距高度、离散单层和二维切片测试。
