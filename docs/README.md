# 项目文档

本目录保存面向开发和汇报的项目级中文文档。

- `更新日志.md`：按日期记录每次功能更新、兼容性变化和验证结果。
- `项目结构.md`：说明整理后的目录职责和模块依赖关系。
- `文件与功能说明索引.md`：逐项说明现有源码、网站、工具、测试、类型和构建文件的职责，并提供推荐学习路线。
- `开发与更新规范.md`：说明以 Vercel 公开部署为前提的开发约束，以及每次修改后必须遵循的详细文档格式。
- `公开地形与Vercel部署.md`：说明公开地形目录、本地离线预处理、环境变量、对象存储和 Vercel 构建流程。
- `Cesium ion公共资产开关.md`：记录公共资产 ID、影像/3D Tiles 生命周期、Token 与署名要求、使用方法、错误处理和验证步骤。
- `UI布局改版方案.md`：记录工作台信息架构、控件迁移和响应式设计约束。
- `Wind3D异常诊断与修复.md`：记录单层 Wind3D 数据出现放射状超长流线时的数据证据、渲染原因、修复命令和验证方法。
