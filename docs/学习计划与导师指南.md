# 编程学习计划与导师指南

> 以 cesium-wind-layer-3d 项目为载体，从零基础到能理解并修改一个真实的 WebGL 三维风场可视化项目。

---

## 一、总体思路

这个项目看起来很难——三维地球、GPU 粒子、气象数据、着色器——但它的每一层都是由基础概念搭建起来的。我们的策略是**自底向上**：先打好地基，再逐层往上盖，每一层都做一个小练习来巩固。

整个计划分为 **6 个阶段**，每个阶段有明确的目标、学习内容和练习任务。你不需要一口气学完，按自己的节奏走，每个阶段扎实了再进入下一个。

---

## 二、阶段计划

### 阶段 0：Web 基础（预计 2-3 周）

**目标：** 能独立写出带有交互功能的网页。

**学习内容：**

| 主题 | 具体内容 |
|------|----------|
| HTML | 标签、属性、语义化结构、表单元素 |
| CSS | 选择器、盒模型、Flexbox 布局、响应式设计基础 |
| JavaScript 基础 | 变量（let/const）、数据类型、条件判断、循环、函数、数组和对象 |
| DOM 操作 | 获取元素、事件监听、动态修改页面内容 |

**你该做的：**
- 跟着任何一套入门教程学习（推荐 MDN Web Docs 的入门指南）
- 每学一个概念就动手写一个小 HTML 文件验证
- 不要试图记住所有 API，重点是理解"变量存数据、函数做事情、事件响应用户"

**练习任务：**
1. 做一个简单的个人介绍网页（练习 HTML + CSS）
2. 给网页加一个按钮，点击后显示/隐藏一段文字（练习 DOM + 事件）
3. 做一个简易计算器（练习函数 + 条件判断 + DOM）

**我（导师）的角色：**
- 你写代码时遇到报错，把错误信息发给我，我帮你分析原因而不是直接给答案
- 你的练习作品我帮你 review，指出可以改进的地方
- 你卡住超过 15 分钟就来问我，我会给提示而不是答案

### 阶段 1：JavaScript 进阶（预计 3-4 周）

**目标：** 能读懂项目中的 JavaScript 代码，理解模块、异步和类。

**学习内容：**

| 主题 | 具体内容 | 在项目中的体现 |
|------|----------|----------------|
| ES Modules | import/export | `src/index.js` 和各模块的导入导出 |
| 异步编程 | Promise、async/await、fetch | `src/data/netcdfLoader.js` 中加载远程数据 |
| 类与面向对象 | class、构造函数、原型链 | `src/wind-3d/WindLayer3D.js` 中的类设计 |
| 数组高阶方法 | map/filter/reduce/forEach | 数据处理和粒子采样中大量使用 |
| 解构与展开 | 对象解构、展开运算符 | 配置合并、参数传递 |
| 错误处理 | try/catch、throw | 数据加载失败、WebGL 不支持时的处理 |
| 模块化工具 | npm、package.json、Vite | 项目的依赖管理和构建 |

**你该做的：**
- 用 Node.js 在命令行练习异步编程（setTimeout、Promise、async/await）
- 尝试用 `npm run dev` 把项目跑起来，观察浏览器的开发者工具（Console 和 Network）
- 从 `src/index.js` 开始，沿着 import 链逐文件阅读，画出模块关系图

**练习任务：**
1. 写一个异步函数，从公开 API 获取天气数据并显示在页面上
2. 把阶段 0 的计算器改写成类（class）的形式
3. 安装并使用 Vite 创建一个简单项目，体验 `npm run dev` 的工作流

**我的角色：**
- 帮你解释 async/await 的执行顺序（这是初学者最容易困惑的概念）
- 带你走读项目代码，解释每个文件为什么存在、它和其他文件的关系
- 你画的模块关系图我帮你验证是否正确

### 阶段 2：3D 与 Cesium 入门（预计 3-4 周）

**目标：** 能在 Cesium 地球上添加基本元素，理解三维坐标系。

**学习内容：**

| 主题 | 具体内容 | 在项目中的体现 |
|------|----------|----------------|
| Canvas 基础 | 2D 绑定上下文、绘制基本图形 | 理解 WebGL 的前置知识 |
| 三维数学基础 | 向量、矩阵、坐标系（笛卡尔 vs 经纬度） | Cesium 的 `Cartesian3` 和地理坐标 |
| Cesium 核心概念 | Viewer、Scene、Camera、Entity、Primitive | `example/app/main.js` 中的初始化 |
| Cesium 数据源 | ImageryProvider、TerrainProvider、3D Tiles | `src/terrain/TerrainController.js` |
| 相机控制 | 飞行、定位、视角限制 | WindLayer3D 中的相机范围控制 |

**你该做的：**
- 去 Cesium 官网（cesium.com）注册免费账号，跟着 Sandcastle 示例学习
- 在项目中运行 `npm run dev`，在 `example/app/main.js` 里尝试修改参数
- 打开浏览器开发者工具，观察 Cesium 的渲染帧率和网络请求

**练习任务：**
1. 在 Cesium Sandcastle 中创建一个地球，添加一个标记点（Entity）
2. 用相机飞行到北京上空，设置不同的俯仰角和航向角
3. 在项目中找到 `main.js` 里 Cesium 初始化的代码，尝试修改默认视角和底图

**我的角色：**
- 帮你建立三维空间直觉——经纬度如何变成三维坐标、相机参数意味着什么
- 解释 Cesium 的生命周期（创建→更新→渲染→销毁），这和阶段 1 的异步编程紧密相关
- 你修改项目代码后，我帮你分析"为什么改了这个参数画面变了/没变"

### 阶段 3：数据与粒子系统（预计 4-5 周）

**目标：** 理解风场数据如何变成可视化的粒子运动。

**学习内容：**

| 主题 | 具体内容 | 在项目中的体现 |
|------|----------|----------------|
| NetCDF 数据格式 | 什么是 NetCDF、维度、变量、属性 | `src/data/netcdfLoader.js` |
| 风场数据 | U/V 分量、经纬度网格、高度层 | `src/data/weightedParticleSampler.js` |
| 粒子系统原理 | 粒子生命周期、位置更新、速度积分 | `src/rendering/windParticleSystem.js` |
| 插值算法 | 双线性插值、如何从网格数据中取任意点的值 | 速度计算着色器中的插值逻辑 |
| 动画循环 | requestAnimationFrame、帧率、时间步长 | 粒子的逐帧更新 |

**你该做的：**
- 先不碰代码，在纸上画出"粒子从出生到消亡"的流程图
- 用 console.log 观察 `netcdfLoader.js` 加载数据后返回的对象结构
- 调整粒子数量、生命周期等参数，观察视觉效果的变化

**练习任务：**
1. 在 2D Canvas 上实现 10 个粒子从左到右的匀速运动（不用 Cesium）
2. 加入随机性：每个粒子有随机的初始位置和速度
3. 加入边界处理：粒子飞出画面后从另一边重新出现（项目中也有类似逻辑）

**我的角色：**
- 帮你理解数据从"文件里的数字"到"屏幕上运动的光点"的完整链路
- 用纸笔或简单图示解释双线性插值——它是风场可视化的关键算法
- 你在 Canvas 上写粒子练习时，我帮你对比项目中的实现，指出异同

### 阶段 4：WebGL 与着色器（预计 5-6 周）

**目标：** 能读懂项目中的 GLSL 着色器代码，理解 GPU 计算的原理。

**这是整个学习路径中最有挑战性的一环**，也是这个项目最核心的技术。

**学习内容：**

| 主题 | 具体内容 | 在项目中的体现 |
|------|----------|----------------|
| WebGL 基础概念 | 管线、缓冲区、纹理、帧缓冲 | `src/rendering/windParticlesRendering.js` |
| GLSL 语言 | 变量类型、内置函数、uniform/attribute/varying | `src/shaders/` 下所有文件 |
| 纹理作为数据 | 把数字存进纹理、在着色器中读取 | 3D 纹理存储风场速度数据 |
| GPGPU 概念 | 用 GPU 做非图形计算（粒子位置更新） | `src/rendering/windParticlesComputing.js` |
| Transform Feedback | GPU 计算结果回读到缓冲区 | 粒子位置的 ping-pong 更新 |
| 帧缓冲切换 | 渲染到纹理而不是屏幕 | 粒子位置的离线更新 |

**你该做的：**
- 先学 WebGL 基础（推荐 webglfundamentals.org），理解顶点着色器和片元着色器的分工
- 从最简单的着色器开始读：`src/shaders/calculateSpeed.js`，逐行理解
- 在着色器中加注释，用自己的话解释每一行在做什么
- 试着修改着色器参数（比如粒子颜色、速度倍率），观察效果

**练习任务：**
1. 用原生 WebGL 画一个彩色三角形（理解顶点着色器 + 片元着色器的协作）
2. 写一个片元着色器，根据纹理坐标输出渐变色（理解纹理采样）
3. 阅读 `calculateSpeed.js`，在纸上画出数据流：输入是什么、经过什么计算、输出是什么

**我的角色：**
- GPU 编程的概念非常抽象，我会用"工厂流水线"等比喻帮你建立直觉
- 你给着色器加注释后，我帮你检查理解是否正确
- 你修改着色器后画面出了问题，我帮你分析是数据问题还是逻辑问题
- 这个阶段的挫折感会比较强，我会帮你区分"理解上的困难"和"只是需要时间消化的困难"

## 四、学员职责（你该做的事）

### 1. 保持规律的学习节奏
- 建议每周至少投入 8-10 小时
- 每天 1-2 小时比周末突击 10 小时效果好得多
- 编程是技能，需要反复练习来形成肌肉记忆

### 2. 先尝试，再提问
- 遇到问题时先自己尝试 15 分钟
- 尝试包括：读报错信息、搜索关键词、检查文档、加 console.log
- 15 分钟后还卡住再来问我，带上"我试了什么、发生了什么"
- 这样你学到的东西会深刻得多

### 3. 写代码时保持思考
- 不要复制粘贴代码然后祈祷它能工作
- 每写一行都问自己：这行在做什么？为什么需要它？
- 能解释给别人听 = 真正理解了

### 4. 记录学习笔记
- 建议准备一个笔记本或笔记软件
- 每天记录：今天学了什么、遇到什么困难、怎么解决的
- 这些笔记也是你以后回顾的宝贵资料

### 5. 主动阅读项目代码
- 不要只看我推荐的代码，自己去探索
- 尝试回答"如果把这段代码删掉会怎样"——然后真的删掉试试看
- 阅读好的代码和写出好的代码同样重要

### 6. 允许自己犯错
- 你会写出很丑的代码、会犯低级错误、会忘记之前学过的东西
- 这完全正常，每个程序员都是这样过来的
- 犯错 → 理解为什么错 → 修正 → 记住，这是最高效的学习路径

## 七、如何开始第一步

今天就可以开始。打开你的编辑器（推荐 VS Code），创建第一个 HTML 文件：

```html
<!DOCTYPE html>
<html lang="zh">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>你好，世界！</h1>
    <p>这是我的第一个网页，我正在学习编程。</p>
    <button id="myButton">点我试试</button>
    <p id="message"></p>

    <script>
        const button = document.getElementById('myButton');
        const message = document.getElementById('message');
        let count = 0;

        button.addEventListener('click', () => {
            count++;
            message.textContent = `你点击了 ${count} 次`;
        });
    </script>
</body>
</html>
```

保存为 `index.html`，用浏览器打开，点击按钮——恭喜你，你写了第一个有交互功能的网页。

当你准备好了，告诉我，我们就从这里开始。
