# 文件与功能说明索引

## 1. 文档目的

本文按职责列出项目中需要维护的源码、网站、工具、测试、类型和构建文件，说明每个文件的作用、运行环境和进一步阅读入口。生成目录、缓存、用户数据和第三方依赖不作为源码逐文件说明。

## 2. 根目录与构建

| 文件或目录 | 作用 | 运行/使用位置 |
| --- | --- | --- |
| `AGENTS.md` | 项目长期开发、Vercel、注释、文档和文件管理约束。 | 所有开发任务 |
| `package.json` | 包信息、依赖和开发/测试/库构建/站点构建命令。 | npm、Vercel |
| `vite.config.js` | npm 库 ES/CJS 构建，入口为 `src/index.js`，Cesium 作为外部依赖。 | `npm run build` |
| `vite.example.config.js` | 公开工作台生产构建，根目录为 `example`，输出 `site-dist`。 | `npm run build:vercel` |
| `example/vite.config.js` | 示例开发服务器配置，使用 Cesium 插件并默认监听 3000。 | `npm run dev` |
| `vercel.json` | 指定 Vercel 构建命令、输出目录和 clean URLs。 | Vercel |
| `build-package.js` | 把 `dist`、类型、README、许可证和精简 package.json 组成发布目录。 | `npm run build` 后半段 |
| `readme.md` | 中文项目入口、安装和使用说明。 | GitHub/npm |
| `README.en.md` | 英文项目说明。 | GitHub/npm |
| `readme2.md` | 历史或补充说明；引用前应确认是否仍与当前实现一致。 | 维护参考 |
| `LICENSE` | MIT 许可证。 | 发布 |
| `assets/` | 文档演示图片，不自动进入网站构建。 | README |
| `ui_design_test/` | UI 独立草案，不是正式 Vercel 页面。 | 设计参考 |
| `index.html`、`favicon.png` | 根目录历史入口/图标；正式工作台入口位于 `example/`。 | 兼容或历史参考 |

`dist/`、`site-dist/`、`node_modules/` 和 `cesium-wind-layer-3d/` 是生成或依赖目录，不应手工维护其中内容。

## 3. 核心库 `src/`

### 公共入口

| 文件 | 作用 |
| --- | --- |
| `src/index.js` | npm 包统一导出，保持外部导入路径稳定。 |

### 基础与数据

| 文件 | 作用 |
| --- | --- |
| `src/core/customPrimitive.js` | 把 Cesium Draw/Compute Command 包装成场景 Primitive。 |
| `src/core/shaderManager.js` | 装配 ShaderProgram、属性和 uniform。 |
| `src/core/utils.js` | 配置深合并和 U/V/W 风速计算。 |
| `src/core/verticalSelection.js` | 把真实高度模式换算为 GPU 纹理高度范围。 |
| `src/data/netcdfLoader.js` | NetCDF-3 格式检测、读取、变量匹配、坐标排序和数组重排。 |
| `src/data/weightedParticleSampler.js` | 按风速权重生成粒子初始位置。 |

### 图层与渲染

| 文件 | 作用 |
| --- | --- |
| `src/wind-2d/WindLayer2D.js` | 提取二维水平层、W 清零并固定显示高度。 |
| `src/wind-3d/WindLayer3D.js` | 三维风场公共图层、相机参数和生命周期。 |
| `src/layers/WindLayerManager.js` | 多个二维/三维风场的统一管理。 |
| `src/rendering/windParticleSystem.js` | GPU 粒子系统总协调和资源重建。 |
| `src/rendering/windParticlesComputing.js` | 风场纹理、粒子纹理和计算命令。 |
| `src/rendering/windParticlesRendering.js` | 流线绘制、framebuffer 和双缓冲。 |
| `src/shaders/calculateSpeed.js` | 风速采样和推进计算 Shader。 |
| `src/shaders/updatePosition.js` | 粒子位置更新 Shader。 |
| `src/shaders/postProcessingPosition.js` | 越界、丢弃和重生 Shader。 |
| `src/shaders/segmentDraw.js` | 线段顶点与片元 Shader。 |

### 地形

| 文件 | 作用 |
| --- | --- |
| `src/terrain/createLocalTerrainProvider.js` | 从可访问 URL 创建 quantized-mesh Provider。 |
| `src/terrain/TerrainController.js` | 椭球、世界和本地地形切换状态机。 |

详细数据流、示例和学习顺序见各子目录 `README.md`。

## 8. 从使用到学习的推荐路线

1. 阅读根 `readme.md` 并运行 `npm run dev`。
2. 阅读 `example/README.md` 理解工作台操作。
3. 阅读 `src/data/README.md` 理解输入格式。
4. 阅读 `src/wind-3d/README.md` 和 `src/rendering/README.md` 理解图层与 GPU 管线。
5. 阅读对应 `tests/`，理解边界条件和错误处理。
6. 需要处理 NC 或 DEM 时，再进入 `tools/` 文档。
7. 准备上线时阅读 `docs/公开地形与Vercel部署.md` 并执行 `npm run build:vercel`。
