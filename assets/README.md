# 项目说明图片

`assets/` 保存根 README 或项目介绍使用的图片和动画，不参与核心库运行，也不会自动成为 Vercel 示例网站资源。

## 现有文件

- `三维风场.gif`：三维风场效果演示。
- `三维风场1.gif`：另一组视角或参数下的效果演示。

## 管理规则

- 图片应只用于项目说明，并确保具有可公开分发的权利。
- 更新文件名时同步修改根 `readme.md`、`README.en.md` 等引用。
- 大型 GIF 会增加仓库和文档加载体积，新增前应评估压缩、视频或静态截图是否更合适。
- 网站运行时需要的资源应放入 `example/` 的 Vite 依赖或 `example/public/`，不要假设本目录会进入 `site-dist`。
